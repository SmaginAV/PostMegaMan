# Редактор тела основного запроса

Автономная сборка CodeMirror 6 с языком JSON. HTML не обращается к сети. Пользовательское тело передается через значения скрытых textarea, сериализованные как JSON; оно не вставляется в код страницы.

## Воспроизведение сборки

Нужен Node.js 24.21.0 или совместимый с закрепленной версией Babel. Из этого каталога:

```powershell
npm ci --ignore-scripts --no-audit --no-fund --offline=false
node build-editor.mjs
Copy-Item -LiteralPath editor.html -Destination '../Templates/РедакторЗапросаHTML/Ext/Template.txt'
```

Скрипты установки зависимостей отключены. Используется пакет бинарного esbuild для текущей ОС. `package-lock.json` фиксирует версии и контрольные суммы загрузок; `manifest.json` фиксирует исходники и хеш поставленного HTML. Полные лицензии собраны в `LICENSES.md`; лицензии всех 13 пакетов, вошедших в редактор, также включены в HTML-ресурс EPF.

Сначала esbuild объединяет модули, затем Babel переводит код для Safari 11, после чего esbuild с целью ES2015 выполняет минификацию. Это необходимо для встроенного WebKit 1С: современный минификатор с целью ESNext может вернуть неподдерживаемый optional chaining.

JavaScript вставляется в HTML через функцию замены: это сохраняет буквальные `$&` в минифицированном коде. Строковая замена интерпретировала их как шаблон и повреждала обработчик Enter. Сборка отклоняет результат с незамененным маркером `__EDITOR_BUNDLE__`.

## Обмен с формой

BSL записывает JSON-команду в `pm-command`, вызывает `pm-go.click()` и синхронно читает `pm-result.value`. Ответ содержит идентификатор сеанса и ревизию; полный текст возвращается только по `snapshot`. При вводе обновляются малые метаданные `pm-meta`; клиентский таймер читает их только на активной странице запроса. На сервер при каждом символе ничего не отправляется.

Явная замена тела создает новый сеанс и сбрасывает историю. Обычный ввод и переключение вкладок сохраняют экземпляр редактора. При закрытии формы таймер отключается и экземпляр уничтожается. Резервный режим использует прежнее многострочное поле 1С.

Вставляемый фрагмент приводится к переносам строк текущего документа через `clipboardInputFilter`. Уже загруженное тело остается точным. Вставка LF в CRLF или наоборот не отключает подсветку; незавершенный JSON и повторяющиеся поля также остаются редактируемыми. Отмена и повтор проходят через обычную историю CodeMirror. Загружаемое тело со смешанными переносами по-прежнему открывается в резервном поле для сохранения исходного текста.

При загрузке тела редактор сначала измеряет фактическую область HTML-поля и подготавливает видимые строки, затем показывает готовое содержимое. Дополнительный синтаксический проход ограничен 20 мс; весь документ на каждый символ не разбирается. В WebKit без ResizeObserver перед кадром сравниваются размеры области и параметры шрифта; при их изменении выполняется повторное измерение. Это локальные проверки геометрии, без чтения всего тела или вызова сервера. Отложенные кадры предыдущего экземпляра отменяются при замене и закрытии.

Во встроенном WebKit 8.3.27.2074 также отсутствует IntersectionObserver. В этом случае событие прокрутки явно запускает requestMeasure; публичное чтение lineBlockAtHeight завершает измерение синхронно. Перед кадром проверяется позиция прокрутки, поскольку WebKit может доставить событие с задержкой. Это обновляет видимые строки без щелчка по тексту. Проверка не меняет документ, историю и ревизию, не читает полное тело и не вызывает сервер. В движках с IntersectionObserver остается стандартное обновление CodeMirror.

Цвет выделенного текста задан явно: тёмный #202020 на светло-голубом #cde3fa. Это предотвращает белые символы, которые встроенный WebKit задает по умолчанию при прозрачном стандартном выделении CodeMirror. Стиль применяется к строкам и токенам, сохраняя текст и выделенный диапазон.
