# Генерация cURL

1. Открой запрос или активный черновик. Укажи метод, URL, параметры, авторизацию, заголовки и тело.
2. Нажми **Сгенерировать cURL** справа от **Импорт**. Предварительное сохранение не требуется.
3. Выдели текст в многострочном поле и нажми Ctrl+C. Поле доступно только для чтения.
4. Закрой окно кнопкой **Закрыть**, Esc или крестиком. Изменив запрос, открой окно повторно — текст должен обновиться.
5. Команду можно вставить в **Импорт → Импортировать из cURL**. Для запуска в терминале используй POSIX/Bash, cURL 7.43+ и UTF-8 окружение. PowerShell/cmd имеют другой синтаксис.

Просмотр не выполняет HTTP, не запрашивает JWT, не записывает файлы и не копирует текст автоматически. В команде видны действующие секреты запроса. Настройка «на клиенте/на сервере» относится к 1С; cURL запускается в выбранном тобой терминале.

## Примеры

Все значения авторизации демонстрационные. `example.invalid` — адрес-заглушка; для отправки его нужно заменить на свой тестовый сервер. Файлы содержат полные команды, пригодные для проверки импорта без запуска.

| Файл | Что проверить |
|---|---|
| [get-query.sh](get-query.sh) | GET; две активные пары `a`, кириллица в query и пустое значение |
| [complex.sh](complex.sh) | POST JSON; апостроф, кавычки, метасимволы и явно пустой `X-Empty` |
| [basic-empty.sh](basic-empty.sh) | Basic с логином `demo` и явным пустым паролем |
| [bearer.sh](bearer.sh) | Единственный заголовок Bearer без получения нового токена |
| [text-edge.sh](text-edge.sh) | Начальный `@` в теле передаётся как текст; Content-Type не добавляется |

Сгенерированная команда сохраняет тело буквально. При обратном импорте корректный JSON по прежним правилам может получить читаемые отступы; JWT представляется как Bearer, API key — как обычный заголовок/query. Прежние лимиты импорта сохраняются, например 2048 символов в значении заголовка: экспорт не обрезается, а импорт превышения отказывает с объяснением.

## Ручная проверка в 1С и Postman

- Внеси последний символ в редакторе и сразу нажми генерацию. Проверь его, повторяющиеся query-пары и отсутствие отключённых параметров. Данные старого ответа не должны попасть в команду.
- Скопируй длинный текст целиком; проверь прокрутку и изменение размера окна. Закрой через Esc и крестик, затем повторно открой. Проверь, что основной редактор доступен и Tab/Shift+Tab продолжают менять отступы.
- У сохранённого запроса просмотр сам не добавляет `(*)`. Полученный двоичный файл по-прежнему скачивается без новой отправки. При переходе с сохранением **Да** форма остаётся доступной.
- В Postman открой **Import**, вставь команду как raw text и проверь предварительный результат: метод, полный URL/query, заголовки, Basic/Bearer и тело. Повтори для GET, сложного POST, Basic и Bearer, не отправляя запрос автоматически. Запиши версию Postman и результат: проверка собственного импорта в 1С её не заменяет.
- Папка/пустой выбор WorkSpace и выполняющаяся операция блокируют кнопку. В самостоятельном режиме без WorkSpace она работает с текущими полями.

NULL, двоеточие в Basic-логине и HEAD с непустым телом не представляются выбранным форматом и отклоняются без частичной команды. Ошибки URL, заголовков, GET с телом и отсутствие JWT также показывают причину.
